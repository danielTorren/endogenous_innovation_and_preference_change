# Paper figure builder

`build_figures.py` turns results folders into the figures the paper ships with.
Drop the folder names into the `RUNS` dict at the top of the file, then:

```bash
python -m package.paper_figures.build_figures
```

For each figure it re-plots from the results folder (calling existing plotting
code -- no simulation, no duplicated plotting logic), copies the PNG into
`docs/paper/` under its number in the paper, and rewrites the matching
`\includegraphics` path in the `.tex`.

| | destination |
|---|---|
| manuscript figure *n* | `docs/paper/Figure_<n>.png` |
| supplementary figure *n* | `docs/paper/supplementary_figs/Supp_Figure_<n>.png` |

Figures are matched to the `.tex` by their `\label{fig:...}`, not by position,
so reordering figures in the document is safe. Only figures that were actually
built get their path rewritten -- a figure you have not generated keeps its old
path rather than pointing at a file that does not exist. The `.tex` is backed up
to `<name>.tex.bak` before each rewrite.

## Flags

| Flag | Effect |
|---|---|
| `--list` | show the manifest, what is ready, and what is missing; change nothing |
| `--only 3,S6,S11` | build a subset (`S` prefix = supplementary) |
| `--skip-plot` | reuse the PNGs already in the results folders |
| `--no-tex` | copy figures but leave the `.tex` files alone |
| `--dry-run` | report what would happen, write nothing |

Start with `--list`: it prints every figure, where its PNG will come from, and
which `RUNS` entry is still empty.

## Figures that are not model output

Main Figure 1 and supplementary Figures 2-4 are not generated by the model. Put
their source images in `docs/paper/static_figs/` under the filenames listed in
`STATIC_SOURCES` and they get copied and renumbered with everything else. If the
image is already sitting at its destination (as main Figure 1 is), it is left
alone.

## Which run makes which figure

`RUNS` keys map onto the generation scripts as follows.

| `RUNS` key | Figures | Generated by |
|---|---|---|
| `calibration` | 2, S5 | `package/generating_data/calibration_gen.py` |
| `single_policies` | 3 | `package/analysis/vary_single_policy_gen.py` |
| `policy_pairs` | 4 | `package/analysis/endogenous_policy_intensity_pair_gen.py` |
| `low_intensity` | 5 | `package/analysis/low_policy_intensity_gen.py` |
| `single_experiment` | 6 | `package/generating_data/single_experiment_gen.py` |
| `used_car_capacity` | 7 | `vary_single_param_gen.py` over `max_num_cars_prop` |
| `posterior` | S1 | `package/calibration/sbi_single_seed_gen.py` |
| `local_sensitivity` | S6 | `package/supplementary_runs/fig06_local_sensitivity_gen.py` (ten folders, panel order a-j) |
| `sobol` | S7, S8 | `package/supplementary_runs/fig07_08_sobol_gen.py` |
| `bau_grid` | S9, S10 | `package/supplementary_runs/fig09_10_bau_gen.py` |
| `grid_beta_carbon` … `grid_achi_rebate` | S11-S14 | `package/supplementary_runs/fig11_14_policy_grid_gen.py` |

See `package/supplementary_runs/README.md` for the generation side: run counts,
wall-clock, and the SLURM jobs.

## The BAU baseline for Figures S11-S14

`policy_sensitivity_plot.load_and_plot_combined` needs `data_cross_bau.pkl`, and
a `cross_*` run only has it if its BAU sweep finished. The BAU baseline contains
no policy, so it depends only on the physical parameter: one BAU run serves both
policies on that axis. `grid_bau_beta` and `grid_bau_achi` name the folder to
borrow it from; leave one empty to use each figure's own folder.
